# КотоДурак

Карточная игра «Подкидной дурак» в кото-тематике — одиночная партия против трёх ИИ в браузере.

Стек: React 19 + TypeScript + Vite + Tailwind. Без бэкенда.

## Запуск

```bash
npm install
npm run dev
```

## Проверки

```bash
npm run test   # 21 тест логики движка и ИИ
npm run build  # прод-сборка
```
