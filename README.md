# КотоДурак 🐈‍⬛

Одиночная браузерная игра в подкидного дурака на 36 карт с оригинальной кото-тематикой.
React + TypeScript + Vite, без бэкенда — вся логика работает локально в браузере.

## Запуск

```bash
npm install
npm run dev      # dev-сервер с HMR
npm run build    # production-сборка в dist/
npm run preview  # раздача собранного dist/
npm test         # тесты логики (Vitest)
```

## Управление

- **Клик/тап** по карте руки — выбор (атака, защита, подкидывание).
- **Перетаскивание** (мышь или палец): карту руки можно бросить прямо на цель —
  на небитую карту стола при защите, в центр стола при заходе или подкидывании.
- Кнопки «Ходить», «Беру», «Пас» дублируют жесты.

## Режимы игры

- **Дуэль** — один ИИ-противник
- **Три кота** — два ИИ-противника
- **Котобанда** — три ИИ-противника

Все играют сами за себя: союзов и подыгрывания между ИИ нет.

## Сложности ИИ

- **Котёнок** — ходит почти случайно, иногда «радостно» берёт карты, которые мог бы побить.
- **Дворовый кот** — осторожная игра: отбивается дешевле всего, козыри бережёт, подкидывает слабое.
- **КотоМагистр** — тактика: помнит сброс и чужие взятия, оценивает вероятность, что защитник сможет побить карту, считает силу рук противников.

ИИ не жульничает: на вход подаётся только публичная информация — собственная рука, стол, козырь, размеры чужих рук и сброс (см. `PlayerView` в `src/game/types.ts`). Это зафиксировано тестом.

## Правила (классический подкидной дурак)

- Колода 36 карт (6–Т четырёх мастей), сдаётся по 6. Открытая карта под колодой задаёт козырь и забирается последней.
- Первым ходит владелец младшего козыря.
- Атакующий заходит картой или несколькими картами одного достоинства. Защитник бьёт каждую: старшей картой той же масти или козырем; козырь — только старшим козырем.
- Остальные коты подкидывают карты достоинств, уже лежащих на столе. Лимит: 5 карт в первом заходе, 6 в последующих, и не больше, чем карт у защитника.
- Заход окончен, когда всё отбито и никто не подкидывает («бито»), либо защитник берёт стол.
- **Взявший забирает весь стол, включая уже побитые карты.** После этого остальные могут докидывать вдогонку («хвост») — теми же достоинствами, пока не скажут «пас» по кругу.
- После захода все добирают до шести: атакующий, остальные по часовой стрелке, защитник — последним.
- Кто избавился от карт при пустой колоде — выбыл. Последний с картами — дурак. Если все избавились одновременно — ничья.
- Переводов, союзов и обмена шестёрки нет.

### Задокументированные решения по неоднозначностям правил

1. **Патовая ничья.** Если в позиции «трое КотоМагистров против КотоМагистра» возможно бесконечное легальное циклирование карт (колоды нет, руки не уменьшаются), введено правило троекратного повторения позиции: если одна и та же позиция (атакующий, руки всех игроков, сброс, колода) встречается трижды, партия объявляется патом и заканчивается ничьей. Это единственное добавление к классическим правилам; без него автопилотные партии на максимальной сложности могли бы не завершаться.
2. **Порядок добора** — строго: атакующий → остальные по часовой стрелке → защитник последним (по ТЗ).

## Архитектура

```
src/
  game/            — ядро, не зависит от UI и графики
    types.ts       — типы, PlayerView (публичная информация для ИИ)
    deck.ts        — колода, детерминированный PRNG (mulberry32, сидируемые партии)
    engine.ts      — GameEngine: чистая машина состояний правил (заход, подкидывание, взятие, добор, выбывание)
    ai.ts          — три уровня ИИ поверх PlayerView
    controller.ts  — GameController: оркестрация ходов ИИ, фразы, события для звука
    cats.ts        — персонажи и описания сложностей
    sound.ts       — синтезированные звуковые эффекты (Web Audio API, без файлов)
    __tests__/     — 21 тест: правила, порядок добора, взятие, вдогонку, завершение партий, отсутствие утечек информации ИИ
  components/game/ — UI
    GamePage.tsx   — игровой стол, подсветка легальных ходов, кнопки действий, drag & drop (мышь и тач)
    Menu.tsx       — главное меню, режимы, сложности, правила
    CardView.tsx   — карта: рубашка с орнаментом КотоИмперии, угловые достоинства
    CatSvg.tsx     — параметрические SVG-иллюстрации котов (36 уникальных карт)
```

Движок (`GameEngine`) не импортирует React и может крутить партию без UI — так работают
автотесты ИИ-против-ИИ (все комбинации «сложность × количество ИИ» × 12 сидов завершаются).

## Проверки

- 21 юнит-тест логики (`npm test`).
- Автопилот: 9 комбинаций сложность × число ИИ × 12 сидов — все партии завершаются без зависаний.
- Ручной прогон в браузере (Chromium): полная партия против трёх КотоМагистров до победного оверлея, реванш, мобильная вёрстка и сенсорное управление — без ошибок в консоли.
